两个 AI 先谈，人最后点头

你拉两个 agent 进来（DeepSeek、Codex 都行）。一个做设计、一个做复核，先把接口方案对齐； 方案稳定后把前端同事拉进来，前端和后端各点一次「确认」，就可以开工了。
