# 成员电脑本地连接器

服务器维护房间、消息与协作状态。成员电脑主动连接服务器，以一次性十分钟配对码换取设备令牌，明确登记允许分析的项目，再运行连接器。网页只能选设备上报的项目标识和 Codex/DSH，不接受远端任意路径。项目绝对路径和 CLI 认证仅保存在成员电脑。旧版同机 project_dir 继续兼容；绑定设备后绝不回落到服务器 CLI。

## 数据和协议

增量新增设备、配对码、设备工作区、连接器任务表；rt_rooms 仅补 device_id/workspace_id，原配置和数据保留。设备 token 和配对码只存 SHA256，配对码一次有效。网页管理沿用 V1 内网信任边界，暂不提供用户登录或按人权限。

网页 API：POST /api/rt/devices/pairing、GET /api/rt/devices、DELETE /api/rt/devices/:id，以及 PATCH 房间绑定设备/工作区。

连接器 API：POST /api/rt/connector/pair、hello、claim、attempts/:id/progress、complete、fail。除 pair 外均要求设备 Bearer token；claim 最多等待 25 秒。hello 仅上报执行器和工作区 id/name，不上报路径。服务端任务只含工作区标识、执行器、模型名和只读分析提示，不下发已存 URL/Key，原设置保留供旧模式使用。

任务领取原子分配全新 attempt_id，设备串行执行。60 秒租约、3 秒执行心跳，断网或失去租约本机停止进程；最长执行时间沿用 RT_LOCAL_TIMEOUT_MS（默认二十分钟）。排队超过 90 秒失效。取消、重试、移出成员、吊销设备、工作区变化、服务重启封住旧回传。服务定时扫描超时任务。最终完成复用现有 finishReply/settleCollaboration，保持最多六次、只读、需要人时暂停、审查通过不自动开发。

## 本机工具与网页

CLI 支持 pair/add-workspace/list/run，配置权限 600，以独占锁防止同一配置重复运行，执行时重新校验项目路径和符号链接。复用现有 Codex/DSH spawn 参数、只读权限、JSONL 解析及进程组清理。Token 不出现在命令行，配对码由终端交互输入；不启动本机 HTTP 服务。

侧栏增加电脑/项目选择、配对和吊销设备。清楚展示在线状态与执行器，保留同机目录高级入口。配对指引提供真实运行命令，不调用真实模型或做演示。

## 验证与上线

离线测试覆盖一次性配对、鉴权、白名单、原配置保留、任务领取/进度/取消、重复迟到结果、断线租约、重启、协作交接与六次上限；本机用注入假执行器验证，不运行真实模型。测试、TypeScript、前端语法通过后提交推送。服务器仅在既有应用目录操作：记录旧镜像，停止本项目，备份数据库，构建，rm -f（不加 -v），up -d；只读核验配置哈希、数据、文件和健康状态。
